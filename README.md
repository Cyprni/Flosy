# نظامي المالي

لوحة تحكم مالية شخصية بالعربية (RTL) - HTML/CSS/JS بدون أي مكتبات.

## التشغيل في Visual Studio Code
1. File > Open Folder ثم اختر مجلد `nizami-finance`
2. افتح `index.html` وشغّله بإضافة **Live Server** (Open with Live Server)، أو افتحه مباشرة في المتصفح.

## الملفات
- `index.html` الهيكل
- `css/style.css` التصميم (يدعم الوضع الداكن والجوال)
- `js/app.js` الحسابات والتفاعل والأيقونات (SVG داخل الملف)

البيانات تُحفظ في localStorage داخل متصفحك فقط.
